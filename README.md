# Avaliação de Algoritmos

Este repositório contém as soluções para os quatro problemas da avaliação de algoritmos:

1. [Problema do Troco](problema1/README.md) - Implementação de algoritmos para resolver o problema do troco usando diferentes abordagens.
2. [Problema do Abastecimento de Combustível](problema2/README.md) - Solução para determinar o menor tempo possível gasto nos postos de combustível.
3. [Problema da Loja de Livros](problema3/README.md) - Implementação do problema da mochila aplicado a uma loja de livros.
4. [Problema das Moedas](problema4/README.md) - Solução para o problema de contagem de formas de fazer troco com moedas disponíveis.

## Estrutura do Repositório

Cada problema está em seu próprio diretório, contendo:
- Um arquivo `.cpp` com a implementação das soluções
- Um arquivo `.txt` com explicações teóricas
- Um arquivo `README.md` com instruções específicas

## Compilação e Execução
